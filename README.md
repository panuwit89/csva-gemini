# PER.AI FastAPI for Chatbot Service
## Clone project
```
git clone https://github.com/panuwit89/csva-gemini.git
```
## Change directory
```
cd csva-gemini
```
## Install require libraries
```
pip install -r requirements.txt
```
## Start service
```
python main.py
```
